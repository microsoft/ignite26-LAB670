# Step 1: create or sign in to your GitHub account

Start here, **before Work IQ installation, PowerShell hydration or playbook
curation**. Keep the GitHub identity separate from your issued Microsoft lab
identity.

## Create and verify your account

1. Open [github.com](https://github.com). If the instructor supplied an approved
   GitHub account, or you already have an approved account with the required
   Copilot access, sign in instead of creating another account.
2. Otherwise, open [Sign up for GitHub](https://github.com/signup?return_to=https%3A%2F%2Fgithub.com%2Ffeatures%2Fcopilot&source=login).
   Use an instructor-approved email address. Use the issued lab email only if
   external GitHub registration is permitted and you can open that mailbox.
   Do not use a temporary lab mailbox for an account you intend to retain.
3. Choose an available username and create a unique password. Recommended:
   use a password manager to generate at least 20 random characters, or generate
   a unique passphrase of at least five unrelated random words that meets the
   displayed requirements. **There is no shared lab password for GitHub.**
   Do not reuse your Microsoft/Skillable password. Store it privately in your
   approved password manager; do not put it in chat, scripts or issues.
4. Follow GitHub's displayed signup and verification prompts yourself.
   When asked to verify your email, open a separate tab for
   [Outlook on the web](https://outlook.office.com) and sign in to the mailbox
   for the address you used. If you used another approved email provider,
   open that mailbox instead.
5. Open GitHub's verification email. Enter its code on GitHub, or follow its
   verification link if that is what GitHub sends. Check Junk Email and request
   a new message if necessary; use the newest code. Do not share the code or
   paste it into Copilot.
6. Finish signup and open [GitHub Copilot](https://github.com/copilot).
   Ask the instructor to confirm access to the required cloud sandbox,
   learner-owned writable workspace and Work IQ managed connector. Creating a
   free GitHub account does not guarantee these capabilities.

If registration, verification or Copilot access is blocked, stop and ask the
instructor. Do not switch to an unapproved identity, enter billing details or
start a paid plan/trial to bypass a restriction.

**Checkpoint:** your approved GitHub account is signed in and its email is
verified. This does not sign you in to Work IQ or hydrate Zava.

**Next:** [Step 2: add Work IQ to GitHub Copilot](02-work-iq-setup.md).

Reference: [Creating a GitHub account and verifying email](https://docs.github.com/en/account-and-profile/how-tos/account-management/creating-an-account-on-github).
